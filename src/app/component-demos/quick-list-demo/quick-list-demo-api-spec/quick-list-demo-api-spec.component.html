Properties

Property Type Default Value Applies To Description
allItems T[] [] Array-backed variants Mutable item array rendered and updated by the component.
formArray FormArray undefined Reactive-form variants Form controls rendered by the component.
itemFactory () => T undefined Array-backed variants Optional typed factory for complete new items. The returned object and its id are preserved. When omitted, the legacy blankItem behavior is used.
blankItem any {} Array-backed variants Legacy fallback that is shallow-cloned when a new item is added without an itemFactory.
addLabel string 'NOT SET' All variants Label used by add buttons and as the compact add icon's native title.
removeLabel string 'Remove item' All variants Native title used by remove icon buttons.
addPossible boolean true All variants Allows adding an item when the maximum-item rule also permits it.
removePossible boolean true All variants Allows removing an item when the minimum-item rule also permits it.
readonly boolean undefined (editable) All variants Hides the add and remove actions when set to true.
maxItems number undefined All variants Optional upper limit for the number of items.
minItems number undefined All variants Optional lower limit for the number of items. Array-backed variants add missing initial items during initialization.

Events

Event Payload Applies To Description
added T Array-backed variants Emits the newly created item after it is appended to allItems.
added null Reactive-form variants Requests a new item. The event handler is responsible for pushing a control into the FormArray.
removed T Array-backed variants Emits the removed item after it is removed from allItems.
removed null Reactive-form variants Emits after the component removes the control from the FormArray.

Projected Content

Content Context Description
<label> None Optional heading projected above the rows.
First <ng-template> $implicit Row template rendered once per entry. The implicit value is the current item for array-backed variants and the current AbstractControl for reactive-form variants.

Array-backed variants infer their item subtype from allItems. Use a typed itemFactory when the component should create complete subtype instances, and use let-item to access the implicit row value: 

interface ContactItem extends QuickListItem {
  firstName: string;
  lastName: string;
}

readonly items: ContactItem[] = [];

readonly itemFactory: QuickListItemFactory<ContactItem> = () => ({
  id: crypto.randomUUID(),
  firstName: '',
  lastName: '',
});

onItemAdded(item: ContactItem): void {
  // $event is inferred as ContactItem.
}

<mad-quick-list
  [allItems]="items"
  [itemFactory]="itemFactory"
  (added)="onItemAdded($event)"
>
  <label>Contacts</label>
  <ng-template let-item>
    <!-- Render controls bound to item. -->
  </ng-template>
</mad-quick-list>
