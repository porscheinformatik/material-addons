Quick Lists let users add and remove repeated groups of fields while the application controls the content and layout of each row.

Use When

  • Users need to enter a variable number of repeated values or field groups
  • Each row needs application-specific controls such as inputs, select fields, or readonly values
  • The number of entries needs optional minimum or maximum limits
  • The repeated values are backed by either an item array or a reactive FormArray

Behavior

  • Array-backed variants render entries from allItems
  • Array-backed variants can use a typed itemFactory to create complete custom items
  • Reactive-form variants render controls from a supplied FormArray
  • The first projected <ng-template> defines each row and receives its value implicitly
  • Regular variants use a labeled add button; compact variants place an add icon in the last row
  • Add and remove actions respect readonly state, permission inputs, and minimum or maximum item limits
  • After a row is added, its first focusable element receives focus

Import the QuickListModule and use the selector matching the data model and action layout: <mad-quick-list> , <mad-quick-list-compact> , <mad-reactive-form-quick-list> , or <mad-reactive-form-quick-list-compact> .
