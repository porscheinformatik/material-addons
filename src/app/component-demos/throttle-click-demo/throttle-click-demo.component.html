Use the throttle-click directive to prevent an action from running repeatedly when users click an interactive element in quick succession.

Behavior

  • The first click is emitted immediately through throttleClick.
  • Later clicks are ignored until throttleTime has elapsed and are not replayed.
  • Ignored clicks do not restart the active throttle window.
  • The directive prevents the native click's default action and stops it from bubbling.

Import ThrottleClickDirective into a standalone component. Existing NgModule-based consumers can import ThrottleClickModule instead.
