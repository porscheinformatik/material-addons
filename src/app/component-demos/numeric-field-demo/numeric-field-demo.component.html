Use to enter and display numeric values with locale-selected dot/comma separators, decimal-place limits, optional rounding, and optional units.

Use When

  • Users need to enter amounts, percentages, dimensions, mileage, power, weight, or other numeric values
  • The input should reject non-numeric characters while preserving normal form behavior
  • The displayed value should use grouping separators and a fixed decimal precision
  • A unit should be displayed with the value without changing the bound numeric value

Behavior

  • Supports ngModel, formControl, and formControlName through Angular forms
  • Invalid characters are prevented during keyboard input; pasted text is parsed up to the first invalid character
  • Programmatic values are truncated by default and rounded when roundDisplayValue is enabled; typed and pasted input is limited to the configured decimal places
  • Missing decimal places are filled on final formatting when autofillDecimals is enabled
  • The Angular LOCALE_ID selects dot/comma separators. Grouping uses the opposite character in groups of three digits; locale-specific spaces and other grouping patterns are not supported.

Apply the directive to a text input, with or without matInput.

Import the NumericFieldModule and use it via the directive madNumericField.
