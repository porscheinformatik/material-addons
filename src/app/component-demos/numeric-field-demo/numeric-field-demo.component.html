Use to enter and display numeric values with locale-aware separators, decimal-place limits, optional rounding, and optional units.

Use When

  • Users need to enter amounts, percentages, dimensions, mileage, power, weight, or other numeric values
  • The input should reject non-numeric characters while preserving normal form behavior
  • The displayed value should use grouping separators and a fixed decimal precision
  • A unit should be displayed with the value without changing the bound numeric value

Behavior

  • Supports ngModel, formControl, and formControlName through Angular forms
  • Invalid characters are prevented during keyboard input and stripped from pasted values
  • Decimal places are truncated by default and rounded when roundDisplayValue is enabled
  • Missing decimal places are filled on final formatting when autofillDecimals is enabled
  • Separators follow the Angular LOCALE_ID through Intl.NumberFormat, with English fallback separators

Because the numeric field is a directive, it can be applied on any input element.

Import the NumericFieldModule and use it via the directive madNumericField.
