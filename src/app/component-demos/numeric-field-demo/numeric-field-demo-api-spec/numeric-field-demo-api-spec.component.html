Properties

Property Type Default Value Description
madNumericField Directive - Applies numeric formatting and Angular forms integration to an input element.
textAlign 'right' | 'left' 'right' Controls the input text alignment. Right alignment is the default for numeric values.
decimalPlaces number 2 Maximum amount of decimal places accepted and displayed.
roundDisplayValue boolean false Rounds the displayed value when enabled. Values are truncated by default.
autofillDecimals boolean false Fills missing decimal places during final formatting, for example on blur.
unit string | null null Optional unit text rendered next to the formatted input value.
unitPosition 'right' | 'left' 'right' Controls whether the unit is rendered before or after the input value.
numericValue number | null | undefined undefined Optional numeric value input for two-way binding through numericValueChange.

Events

Event Type Description
numericValueChange number Emits the parsed numeric value when the displayed input value changes.

Forms Behavior

Feature Description
ngModel Supported through ControlValueAccessor.
formControlName Supported through ControlValueAccessor.
Empty value Returns undefined to Angular forms so required validators work with empty input.
Disabled state Updates the native input disabled property through the value accessor.
