Properties

Property Type Default Value Description
madNumericField Directive - Applies numeric formatting and Angular forms integration to an input element.
textAlign 'right' | 'left' 'right' Controls the input text alignment. Right alignment is the default for numeric values.
decimalPlaces number 2 Maximum fractional digits accepted during editing and shown in the display. Accepts integers from 0 through 100, including numeric strings such as decimalPlaces="0". Empty, fractional, non-finite, or otherwise invalid settings fall back to 2. Programmatic values retain their full precision until an actual edit; increasing this setting can reveal retained digits without changing the model or emitting a value change.
roundDisplayValue boolean false By default, truncates toward zero: at two places, 1.23999 becomes 1.23 and -1.23999 becomes -1.23. When enabled, rounds only the display of programmatic values; exact ties round toward positive infinity (1.235 becomes 1.24; -1.235 becomes -1.23). Typed and pasted input is truncated to the configured decimal places.
autofillDecimals boolean false Fills missing decimal places during final formatting, for example on blur.
unit string | null null Optional unit text rendered next to the formatted input value.
unitPosition 'right' | 'left' 'right' Controls whether the unit is rendered before or after the input value.
numericValue number | null | undefined undefined Optional numeric value input for two-way binding through numericValueChange. Input and change events are processed immediately, including when Angular forms are not used.

Events

Event Type Description
numericValueChange number Emits parsed numbers, including NaN for empty or rejected user edits. Repeated empty input/change events can emit again; unchanged keyup and blur do not, except when final formatting on blur resolves an unfinished edit into a finite number. Programmatic writes and clears, or changes to display precision, rounding, padding, and locale do not emit this event.

Forms Behavior

Feature Description
ngModel Supported through ControlValueAccessor.
formControlName Supported through ControlValueAccessor.
Empty value Empty or rejected edits return undefined to Angular forms and emit NaN through numericValueChange, so required validators work with empty input.
Programmatic writes and resets Restore formatted text immediately without emitting numericValueChange or feeding a user change back to forms, including equal-value writes: after typing 12., reset(12) displays 12 and leaves the control pristine and untouched. Angular forms' own event options still apply. Non-finite programmatic values display empty while the supplied model value is retained.
Disabled state Updates the native input disabled property through the value accessor.

Numeric Text

Complete finite scientific text, such as pasted 1e3, is expanded to a localized decimal display (1,000 with English separators) and truncated to the configured precision. Malformed scientific text, overflow, and explicit NaN or Infinity edits display empty and use the empty-value conventions above. Other unsupported characters retain the existing valid-prefix behavior; for example, English 12.3x45 becomes 12.3.

Locale Behavior

Calling NumberFormatService.prepareSeparators(locale) reformats Angular-managed fields using the retained value. Locale changes do not emit numeric value changes or update the form model.

Locale Source Decimal Separator Grouping Separator
de-DE , .
de-AT , .
en-EN . ,
fr-FR , . (compatibility behavior, not French whitespace grouping)
Other well-formed locales Comma when detected by the runtime, otherwise dot The opposite dot/comma character, in groups of three digits
Well-formed but unsupported locale Uses the runtime's default locale to select the dot/comma pair; English is not guaranteed.
Malformed locale (for example invalid_locale) Throws the runtime locale error; there is no fallback for malformed locale strings.
